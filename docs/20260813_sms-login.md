# SMS login

## Goal

Add SMS login capability with feature parity to ZITADEL's default login UI while preserving this project's architecture and conventions.

## Decisions

- Use `~/opensource/zitadel` as the behavioral reference.
- Reuse the existing flow-v2 session, CSRF, origin, rate-limit, and sealed-cookie infrastructure.
- Build on the existing SMS OTP challenge, resend, and verification primitives rather than introducing parallel transport logic.
- Treat SMS as an enrolled second factor, matching ZITADEL default UI semantics rather than adding phone-number primary identification.
- Keep SMS enrollment outside this login change.
- Preserve existing SMS reachability after password and password-change flows.

## Approach

- Compare current SMS reachability with ZITADEL's default flow.
- Implement the smallest complete parity increment through existing flow-v2 patterns.
- Add automated coverage and verify the browser flow.
